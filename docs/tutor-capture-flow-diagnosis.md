# 讲题拍照流程诊断指南

## 当前设计的完整流程

### 流程 A：从空讲题页开始

1. 打开应用 → 底栏点击"讲题"
2. 看到空页面，有输入框
3. **点击输入框左侧的相机图标** 📷
4. 进入拍照页面（`CaptureScreen`）
5. **拍照或选择图片**
6. 系统自动识别题目（OCR）
7. 显示识别结果（题目文本）
8. **需要用户确认/编辑题目信息**：
   - 科目
   - 题目标题
   - 题目内容（OCR结果）
   - 手写/印刷/混合
9. **点击某个"继续"或"确认"按钮**（这是提交）
10. ✅ 进入讲题会话页，开始讲解

### 流程 B：从已有讲题会话中拍照

1. 已经在讲解一道题的状态
2. 想拍新题或补充材料
3. **点击输入框左侧的相机图标** 📷
4. 进入拍照页面（`CaptureScreen`）
5. 后续步骤同流程 A

## 可能的"发不出去"原因

### 问题 1：找不到"提交/继续"按钮

**症状：** 拍完照、看到识别结果，但不知道怎么继续

**可能原因：**
- 按钮位置不明显（滚动到底部？）
- 按钮被禁用（灰色）
- 按钮文案不清楚（"继续"/"提交"/"确认"？）

**排查方法：**
1. 拍照后，**上下滚动页面**，看看底部是否有按钮
2. 检查是否有必填项（科目、题目标题）没填
3. 截图给我看，我能直接指出按钮在哪

### 问题 2：点了按钮但没反应

**症状：** 点击按钮后，页面无变化或卡住

**可能原因：**
- 网络请求中（如果需要调用 AI 识别）
- 本地保存失败
- 导航逻辑错误（刚才修复的那个 bug）

**排查方法：**
1. 看是否有 loading 提示（转圈/进度条）
2. 等待 10-30 秒看是否有变化
3. 检查是否有错误提示文字

### 问题 3：提交后跳到错误的页面

**症状：** 点了按钮，跳到错题本而不是讲题会话

**状态：** ✅ 刚才已修复（需要重新编译运行）

### 问题 4：根本没有提交按钮（自动提交）

**症状：** 拍照后系统自动处理，没给用户确认机会

**可能原因：**
- 设计为自动流程，识别完直接进入讲解
- 跳过了确认步骤

**排查方法：**
- 观察拍照后是否直接跳转到讲题会话页
- 如果是，这可能是预期行为

## 临时解决方案（如果是按钮问题）

如果是找不到按钮，可以尝试：

1. **滚动到页面底部**
2. **检查页面右上角**是否有"完成"或"✓"图标
3. **检查键盘是否挡住了按钮**（如果是输入框状态，关闭键盘试试）
4. **返回重试**（点返回键回到讲题页，重新拍一次）
