# 学生掌握机制：证据、掌握与记忆把握度

## 目的

这套机制回答三个不同问题，不能把它们压成一个机械分数：

1. 学生过去是否表现出对某个细知识点的理解；
2. 这些判断的证据是否可靠、是否彼此冲突；
3. 学生此刻还能否顺利回忆，以及是否应该安排复习。

长期历史只追加、不因时间而删除；时间只影响“当前记忆把握度”和复习优先级。知识库提供知识结构，错题库保存题目与复习事实，掌握库单独保存学习证据和投影，三者不共享表或事务。

## 为什么不直接采用单一算法

- 经典 Bayesian Knowledge Tracing 把每个知识成分建模为隐含的“会/不会”状态，并用答对、答错更新概率。它适合做基线，但二元状态不足以表达本项目的证据强弱、提示污染、开放回答与冲突；其参数还存在可辨识性问题，不能把一组拟合参数直接解释为学生真实心理状态。
- Performance Factors Analysis 将同一知识点上的成功次数和失败次数分开累计。这支持本项目保留正、负证据，而不是相互覆盖。
- Assistance Model 的研究表明，提示数量和尝试次数包含独立信息。因此“看过答案后答对”或“多次尝试后答对”不能记成一次独立掌握。
- Half-life Regression 以及个性化间隔复习研究把长期学习状态与随时间变化的回忆概率分开。这对应本项目的“历史掌握事实不衰减、当前记忆把握度可变化”。

这些模型用于约束设计和建立比较基线，不作为不可替换的唯一真理。正式参数必须通过真实标注集、时间切分验证和版本化校准得到。

## 分层计算

### 1. 事实接纳

先判断一次行为是否有资格进入掌握库：

- 本地可验证的选择、数值和图上目标：强证据；
- 模型评价的开放回答、明确追问和具体卡点：可修订弱证据；
- 批量导入的错误：只有错误答案、批改标记或错误步骤能定位到细知识点时才形成负证据；
- 模糊聊天、情绪表达、浏览讲解、播放或旋转图形：零证据；
- 学生明确要求“不记录”或请求已过期：零长期写入。

模型只能提交带证据引用的候选，不能提交权重、掌握分或 SQL。权限闸门必须绑定学生、科目、对话代次、题目修订、知识绑定版本、模式版本、记忆权限版本和请求版本。

### 2. 证据特征

不可变事件保留最少但足够重放的结构化特征：

- 正向或负向；
- 选择、数值、图上目标、开放回答、具体卡点、导入错误或复习回答；
- 是否独立作答、是否已展示答案；
- 尝试次数与提示次数；
- 题目家族、呈现形式和细知识点；
- 证据等级、发生时间、归因模型和知识包版本。

不保存模型提示词、原始自由回答或可让模型自行提高权重的字段。

### 3. 历史掌握投影

每科独立投影，同科知识点跨对话共享。投影至少保留：

- 正、负证据质量；
- 分开的成功与失败贡献；
- 独立题目家族数和呈现形式数；
- 冲突状态、趋势和最近有效证据；
- 可解释的日常状态：还没学到、正在熟悉、比较稳、需要再巩固、最近有波动。

同一家族或同一呈现形式要设贡献上限，避免反复做近似题把掌握度刷高。提示、重试和看答案后的正确只能提供有限支持，不能抵消一次可靠的独立错误。低置信归因进入待确认，不提前修改投影。

### 4. 当前记忆把握度

当前把握度从历史投影派生，不能回写或篡改历史事件。它综合：

- 距离最近一次独立成功或失败的时间；
- 经过验证的个人记忆稳定性；
- 过去复习间隔与回忆结果；
- 最近冲突、错误和提示依赖；
- 题目家族覆盖，而非题目总数。

没有足够个人数据时使用保守的分科先验；数据充足后才切换到版本化的个人校准。单纯时间流逝只能降低当前把握度，不能把“曾经掌握”改写为“从未掌握”。

### 5. 复习选择

复习只从学生保存的错题中选题。排序综合当前记忆把握度、近期错误、知识冲突、代表性、预计耗时和疲劳；同一题族每次只选代表题。每日时间预算是硬约束，积压量不能直接变成次日题量。

## 参数治理

- 所有校准参数和投影策略都有稳定版本；历史事件永远保留原版本。
- 新参数只通过离线重放、时间切分验证和分科指标比较发布，禁止在生产设备上静默自我修改。
- 同时评估校准误差、排序质量、长期回忆预测、跨题族迁移和负面归因精确率，不能只优化下一题答对率。
- 样本不足时使用分科共享先验；个人参数必须满足最低独立题族数和最低时间跨度。
- 参数设定保持单调约束：独立正确不应降低掌握，可靠独立错误不应提高掌握，增加提示或展示答案不应提高证据强度。
- 模型升级、知识包升级和校准升级分别版本化，任何升级都能从不可变事件完整重放。

## 性能与模型读取

模型只读取当前题相关、同科、有限数量的掌握摘要，不读取事件全表。摘要按学生、科目、稳定知识标识和投影版本索引；时间线和待确认冲突使用独立索引。一次请求返回日常语言状态、趋势、最近可靠证据时间和是否适合提问，不返回内部权重或置信度。

目标性能：

- 十万条学习事件下，当前题相关掌握摘要 P95 小于 30 ms；
- 知识候选召回 P95 小于 50 ms；
- 投影可分页重放并从已提交游标恢复；
- 同一事实重试、进程恢复和模型迟到均不得重复入账。
