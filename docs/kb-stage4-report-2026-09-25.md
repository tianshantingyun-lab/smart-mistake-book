## 2. ②审计器口径与 I-04 硬验收

### 2.1 审计器：机械预筛，只定位不裁定

判据写在 `tools/kb_build/audit_content_bindings.py:15-22`（表头逐条复述）：

| 代号 | 判据 | 消灭的失败 |
|---|---|---|
| C1 `own-title-detached` | 材料标题与本节点「名字＋全部别名」零词面交集 | 材料挂在一个它标题里一个字都没提的节点上 |
| C1' `own-title-alias-only` | 标题与节点**名**零交集、只在别名里挂上 | 别名污染（J-05）把「错绑」洗成「看着有依据」 |
| C2 `own-subject-detached` | 材料首句主语与本节点「名字＋全部别名」零词面交集 | 面相式标题（I-05 的假阴性来源）只有正文主语还露出真身 |
| C3 `foreign-title-match` | 材料绑在靶区**之外**、标题与靶区某节点名 IDF 加权强匹配（≥0.50 且命中稀有词）且强于其现绑 | 靶区节点的材料被挂到别的节点上 |

三条写在工具里的口径（不是运行期外部输入）：

1. **词面 = CJK 二元组 + ASCII 词元**，不引分词器、不引模型（`audit_content_bindings.py:151-158`）；
2. **`own-title-alias-only` 是自证、不是旁证**：别名表由绑定材料标题回流重建
   （`audit_content_bindings.py:347-348`），所以裁定一律**不依赖别名**；
3. **C4 是复核不是指控**：行里同时写「登记时绑哪 / 现在绑哪 / 现绑节点是否解释得了材料」。
