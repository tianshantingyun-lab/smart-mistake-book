# 教材目录对齐核对 · 四科汇总（2026-09-21）

方法：用官方电子教材的**目录页**（只读目录、不留存页图、不抄正文）与
`standard_chapter_names.json` / 本仓库主题树逐章逐节比对。四份分册明细见同目录
`CHEMISTRY.md` / `BIOLOGY.md` / `PHYSICS.md` / `MATH.md`（各含逐册对照表与差异清单）。

## 一、总体结论（一句话）

**章表是对的，缺陷集中在主题树那一支**：四个学科的章名清单与官方目录逐字一致率
88–100%，但**主题树里 0 个章节点带官方章名**（要么只有"第X章"、要么连章节点都没有），
再叠加一批跨册错位与章层缺失。也就是说：**要修的不是"我们对教材错了"，而是"主题树没把
教材的章层用起来，并且有一批节挂错了册"**。

## 三、必须修的四类（与口径无关，都该修）

1. **跨册错位**（打开一册看到别的册的节名）：
   - 化学 6：`电离平衡` 挂必修一第一章（本属选必1 第三章）；必修二第七章「有机化合物」下挂了
     烷烃（选必3）、分子结构与物质的性质（选必2）、钠及其化合物（必修一）；
     `原子结构与元素周期表` 与 `原子结构与元素的性质` 两节在必修一/选必2 之间**互换册位**；
   - 生物 7：选必2 `人类活动对生态环境的影响` 下挂「群落的演替」、`影响种群数量变化的因素` 下挂
     「种群的数量变化」、`生态系统的能量流动` 里混挂「生态系统的结构/稳定性」——**这类会让学生在
     该主题下学到别节内容**，优先级最高；
   - 物理 19（11 跨册）：选必二第一/二章共 8 节整段搬到必修三第十三章下；
   - 数学 8：`解三角形` 挂必修一第五章（官方在必修二 6.4），且与 `三角函数` 主题重叠 ≥25 条；
     **选必三第七、八章整章脱靶**（条件概率/全概率/正态分布/回归分析等点被塞进"必修第二册·第九十章"），
     而选必三只剩一个章节点。
2. **章层缺失/占位名**：物理 16/16 章节点无官方章名（其中一个直接把编者备注当章名：
   「第十三章（安培力/洛伦兹力/感应定律见选择性必修第二册）」）；化学/生物/数学的章节点也
   全是"第X章"或"第X章第Y节"式占位；选必2/3（化学）、选必3（生物）、选必三（数学）**整册无章节点**。
3. **章表的两处旧版名（生物学）**：选必1 第一章应为「人体的内环境与稳态」、
   选必2 第四章现写「生态环境的保护」（旧 2004 版名，官方为「人与环境」）。
4. **数学的疑似大面积归位错误**：`必修一·第三章·函数的概念与性质` 一个主题挂着 **209 个点**
   （第二名两倍），其中至少 **54 条（约 26%）**官方归属在其他册/章（导数、圆与直线、排列组合、
   复数、概率统计…）——需要单独一轮逐条核（这批不是"主题命名"问题，是"点挂错位置"问题）。

## 四、需要你定的两件事（我不替你定）

**决定 1：教材授权的用法**（见 `kb-textbook-source-verification-2026-09-21.md` 第 5 节）
- A 不申请许可（推荐）：教材只作人工核对参照（本轮即为这种用法）；内容补料走 2027 版《53知识清单》+ 课标对照表；
- B 申请许可：走国家平台渠道（4001910910 / ncetbgs@moe.edu.cn）或人教社版权部门，拿到书面许可再入库；
- C 只做覆盖核对：产出《教材覆盖对照表》作为终验证据（本轮已给出四份分册对照，可据此扩成正式表）。

**决定 2：章节树口径**
- 方案 ①「1:1 对齐教材」：补章节点（化学 8、生物 6、物理 3、数学 2）+ 章节点加官方章名 +
  拆合并（物理 7、数学 16、化学 6）+ 补缺失节（化学 6、生物 7）——**改动面大，但用户看到的目录与教材一致**；
- 方案 ②「允许知识重组，只修错位与占位」（四科代理的推荐，我也倾向这个）：只修第三节第 1、2 类
  （跨册错位 + 章名/章层）+ 生物 2 处旧章名 + 数学那 54 条疑似错位单独核。**收益/风险比最好**：
  学生看到的是"章名对了、没有别册的节混进来"，而知识重组的优点（按方法/模型聚合）保留。
