## 结论

### 章级一致率（两个口径必须分开看）
1. **章表口径 —— 20/20 逐字一致（100%）**。
   `kb_tools/standard_chapter_names.json` 的化学部分与官方目录**逐字相同**：
   必修一 `物质及其变化 / 海水中的重要元素——钠和氯 / 铁 金属材料 / 物质结构 元素周期律`；
   必修二 `化工生产中的重要非金属元素 / 化学反应与能量 / 有机化合物 / 化学与可持续发展`；
   选必1 `化学反应的热效应 / 化学反应速率与化学平衡 / 水溶液中的离子反应与平衡 / 化学反应与电能`；
   选必2 `原子结构与性质 / 分子结构与性质 / 晶体结构与性质`；选必3 `有机化合物的结构特点与研究方法 / 烃 / 烃的衍生物 / 生物大分子 / 合成高分子`。
   → **仓库里的"章"是对的**，`chapter_map.csv`、`chapter_by_source.csv` 也按这些章名在归位知识点。
2. **主题树口径 —— 12/20 有对位章节点（60%），0/20 章节点带章名**。
   必修一/二、选必1 各 4/4 有 `第一章…第四章` 节点，但**全部只有序号、没有章名**；
   选必2（3 章）与选必3（5 章）**连章节点都没有**，主题直接挂在以书名为名的册节点下
   （「物质结构与性质」「有机化学基础」），8 个章的层级在主题树里丢失；另多出 2 个伪章 + 1 个自建章。
   → **章级"缺陷"只存在于主题树这一支，不在章表支**。
