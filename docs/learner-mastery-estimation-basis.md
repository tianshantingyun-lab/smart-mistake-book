# 分科学习掌握估计：实现依据与不可越界规则

本文件约束学生掌握库的通用实现。它不是面向学生的文案，也不针对某道题或测试集调参。

## 1. 三个库的职责必须分开

- 学生错题库保存题目、图片、题目修订、收藏状态和错题组织结果。
- 学生掌握库保存不可变学习事实、归因候选、复核结果、已应用回执和可重放投影。
- 高中知识库保存稳定知识节点、别名、章节映射、关系、方法和资料出处。
- 三库禁止共享 Room 数据库文件，禁止 `ATTACH`，禁止跨库外键。跨库只传带学习者、科目、版本、来源和幂等绑定的有界消息。

## 2. 不把掌握度简化成加减分

掌握投影至少同时表达：

- 历史学习证据的方向、质量、独立性和发生时间；
- 对“学生是否已经掌握”的估计及其不确定性；
- 题目难度、作答形式、提示、重试、查看答案等观测条件；
- 当前记忆把握度，它可以随时间变化，但不能删除或篡改历史掌握事实；
- 冲突状态：新弱证据与稳定结论冲突时先复核，不直接翻转结论。

本地投影必须是确定性的。模型只提交“这条事实可能对应哪些知识点、为什么、引用哪条事实”的受控候选，不能提交最终分数，不能写 SQL，也不能改变权重策略。

## 3. 证据更新规则

1. 先验证事实，再做知识归因；“题目涉及某知识点”不等于“学生在该知识点出错”。
2. 一次作答可关联多个细知识点，但只更新有步骤、错误位置或可验证回答支撑的节点。
3. 相同题面、相同解法结构、同一次展示或同一题族的重复证据属于相关证据，不能线性累加。
4. 正向与负向证据分别使用展示级、题族级预算。负向证据不能耗尽正向预算，正向证据也不能遮蔽重复暴露的负向模式。
5. 已看答案、使用提示或多次重试后的正确只能说明“在当前帮助下完成”，不能形成独立掌握证据。
6. 模型评价的开放回答和具体卡点是可修订弱证据；本地可验证的选择、数值、图上目标和可信答案才可形成强证据。
7. 题目难度和区分度只能来自经验证数据或明确题面约束；模型主观猜测的难度不得直接放大权重。
8. 所有应用必须写入幂等回执。崩溃恢复、网络重试、模型迟到和投影重放不得重复改变掌握状态。

## 4. 建议的可解释投影

- 对每个“学习者 × 科目 × 稳定知识节点”维护历史对数优势、正负有效证据质量、最近强证据时间、独立展示数、独立题族数和不确定性。
- 观测似然同时考虑正确性、提示/重试、题目可信难度、答案可验证性和证据相关性；参数按版本锁定。
- 多知识点题目的证据先在步骤层定位，再进行有界分配；不允许把整题错误平均扣到所有涉及节点。
- 当前记忆把握度作为独立读模型，由历史掌握、距最近有效复习时间和个人回忆速度计算；它只影响复习优先级。
- 面向模型的摘要使用稳定 ID、日常名称、状态、趋势、最近强证据和冲突标志的有界结构；不传完整事件时间线，模型需要更多证据时再通过白名单分页查询。
- 面向学生只投影“还没学到、正在熟悉、比较稳、需要再巩固、最近有波动”等日常表达。

### 4.1 持久结构与索引

- 原始学习事实、观察候选、已归因事件、修订/替代事件和应用回执分别保存；投影表不反向充当事实来源。
- 已归因事件使用单调 `eventSequence`，并保留 `eventId`、学习者、科目、知识节点稳定指纹、方向、质量、证据来源、发生时间和策略版本。
- 知识投影的主键为“学习者 + 科目 + 稳定知识节点指纹”；不能用显示名称或教材章节名作为身份。
- 展示级和题族级预算的主键必须再包含证据方向；正向和负向记录不能共享一行。
- 幂等回执对来源事实、候选、归因修订和跨库消息分别建立唯一绑定；不能只用模型请求 ID 去重。
- 高频读取至少覆盖以下索引：按学习者/科目/事件序列重放，按学习者/科目/知识节点精确查询，按学习者/科目/最近证据查询，按候选状态/重试时间处理，以及按跨库幂等键查回执。
- 重建使用固定大小的 keyset 页面，不使用 `OFFSET`，不在内存中装载完整事件账本；切换新投影前必须核对输入快照、行数、最后排序键和输出摘要。

### 4.2 给模型的低消耗上下文

- 常规讲题只提供当前题直接相关的同科知识摘要，默认不超过 24 个节点；每个节点只含稳定引用、日常名称、当前状态、趋势、最近有效证据时间和是否存在冲突。
- 摘要携带完整的学习者作用域、科目、知识包版本、投影版本和生成时间；缺少任一身份字段时安全拒绝，不以名称模糊匹配。
- 模型如需证据，只能调用白名单的精确节点或有界时间线查询；返回分页结果和继续游标，不返回全库事件。
- 模型写入只能形成 `LearningObservationCandidate` 或归因修订建议，必须引用已经存在的题目/作答事实和允许的知识节点。最终权重、是否入账、冲突处理和投影更新全部由本地策略决定。
- 查询和写入令牌分别绑定当前学习者、当前对话、科目、题目修订、模型任务版本和过期时间；新对话不能读取旧聊天，但可读取同科相关掌握摘要。

### 4.3 校准与验收

- 参数验证使用跨九科、跨题型、跨难度的独立人工标注集；训练、调参与最终评估题必须隔离。
- 除下一次作答预测误差外，还要分别检查负面归因精确率、知识召回率、置信校准、跨科误召、重复证据敏感性和提示/重试后的虚假正向率。
- 在十万事件规模下验证精确摘要、时间线和候选召回的 P95；性能测试必须使用真实 SQLite 索引与分页路径，不能用内存假仓库替代。

## 5. 为什么采用可解释的本地模型

单个学生的本地数据初期稀疏，直接训练深度知识追踪模型既难校准，也难解释一次异常作答为何改变结论。项目采用事件账本 + 版本化、可重放的概率/加权投影，并保留将来用匿名离线研究校准参数的接口。任何新参数必须在跨科、跨题型人工标注集上验证，不能以某道验收题是否通过为目标。

## 6. 研究依据

- Corbett 与 Anderson 的 Knowledge Tracing 将知识掌握作为随练习变化的隐状态，而不是累计分数：<https://doi.org/10.1007/BF01099821>
- Pavlik、Cen 与 Koedinger 的 Performance Factors Analysis 分开建模成功与失败练习，并支持一个行为涉及多个技能：<https://doi.org/10.3233/978-1-60750-028-5-531>
- Settles 与 Meeder 的 Half-Life Regression 将可训练的记忆半衰期用于回忆概率，支持把“历史掌握”与“当前记得多牢”分开：<https://doi.org/10.18653/v1/P16-1174>
- IRT 与知识追踪的结合提醒实现同时考虑纵向学习变化和题目难度/信息量，而不能把每道题视为等价观测：<https://arxiv.org/abs/1803.05926>
