# 教材来源联网核查（2026-09-21）

用户指令：继续下一轮，做一次教材来源的联网核查；教师版源不管（已按 `kb-outstanding-work-2026-09-20.md`
的裁定"明确不读"处理）。

**结论先说**：
1. **官方来源找到了，而且四科全套齐**——人教社官网（`jc.pep.com.cn` → `book.pep.com.cn` 翻页书）
   与国家中小学智慧教育平台（`basic.smartedu.cn`）都提供人教版高中教材电子版，无需登录，四科
   21 册齐（数学 A版 5 / 物理 6 / 化学 5 / 生物学 5）。
2. **但两处官方声明都禁止转载与改编**，国家平台的声明还**点名 App 应用**；教材内容入库并随我们
   的 APK 分发，超出现在获得的许可范围 → **未经许可不得入库**（这一点需要你裁定，见第 5 节）。
3. 技术上也**不建议、也不应绕过**：站点的文字层是**刻意混淆**的（字形码打乱），页面图受
   Referer ACL 保护——规避技术保护措施另有法律风险。
4. 你要的"四科（尤其化学/生物）人教版教材知识点细致入库"这个目标，**内容侧有合规替代**：
   本地已有的 2027 版《53知识清单》四科（教辅，已定使用政策）+ 已抽取在仓的**课标内容要求对照表**
   （覆盖口径）+ 冻结的旧块池（可按块捡回）。是否需要教材原文本身，是产品/法务取舍，我没有替你定。

## 1. 通道核查（逐条实测，含失败原因）

| 通道 | 结果 | 证据/原因 |
|---|---|---|

| `WebFetch` → `jc.pep.com.cn` | 页面可达但**是 JS 空壳** | 只返回标题"中小学教材电子版"；书单由 Vue 客户端渲染 |

## 2. 官方来源详情

  每本书一个「在线阅读」按钮；
- 阅读器：`https://book.pep.com.cn/<书号>/mobile/index.html`（HTML5 翻页书，**无需登录**）；
- 已实测的书号（部分）：化学必修第一册 `1442001121191`、物理必修第一册 `1441001121191`、
  数学**（B版）**必修第一册 `1421001121201`；
- 阅读器技术形态（读 `config.js` 取证）：
  - `totalPageCount=140`（化学必修第一册 140 页）、`largePageWidth=1800 largePageHeight=2546`；
  - 页图路径 `../files/mobile/`，实测 `https://book.pep.com.cn/1442001121191/files/mobile/1.jpg`
    → **200 / 669,729 字节**（单页约 650KB）；
  - **无 Referer 时 403**（`denied by Referer ACL`，Tengine）——防盗链；
  - 文字层：`javascript/search_config.js` 里 `textForPages` 是**打乱字形码的乱码**
    （例：`ࣇ܂۱ದ࿐༝൐Ⴈđໃࣜ൱ಃ҂֤ਸ਼ቓ෰Ⴈ`），即"有文本但被刻意混淆"，属技术保护措施。

## 4. 对项目的含义

1. **教材原文入库：被授权挡住，不是技术问题。** 页图可取、文本层在，但"能取"不等于"可用"。
2. **规避技术保护措施不做。** 站点的字形混淆与防盗链是明确的保护手段；绕过它们去建库，
   风险高于收益，也不符合本仓库一贯的来源合规纪律（教辅也只"提取结构化结论与知识目录节点，
   不保存原文段落"）。
3. **你的验收目标可以合规达成。** "四科人教版教材知识点细致入库"的实体是**知识点**，而知识点
   覆盖率与归属我们已有三层承载：
   - **章表**：`chapter_map.csv` / `chapter_by_source.csv` 已是 2019 人教版（A版）目录口径
     （结构与归属靠它，本轮核查的教材清单正好用来**核对该目录是否与 A 版一致**）；
   - **课标内容要求对照表**：仓内已有 `knowledge-production/curriculum-coverage-*`（课标是
     政府文件，另一个口径）；
   - **内容源**：本地 2027 版《53知识清单》四科（教辅，使用政策已在 O 节定：只提结构化结论），
     W-2 的 1,232 个薄料节点按它的 note 指向补料即可。
4. **教材可作为"人工核对参照"**（不落盘、不进包）：例如核对章节目录、核对某知识点的表述边界——
   这是"个人学习使用"范围内的查阅行为。若要机械化使用，需先拿许可。

## 6. 顺带做的抽查：我们的章表 vs 官方教材目录（化学必修第一册）

在"个人学习使用"范围内取目录页（`files/mobile/6.jpg` 与 `7.jpg`）目视比对，**只看目录、不留存
教材页图**（核查后已删除；本文件只记比对结论）：

| 官方目录（人教版 2019 · 必修第一册） | 本仓库 `chapter_by_source.csv` | 结论 |
|---|---|---|
| 第一章 物质及其变化 | 第一章 物质及其变化 | ✅ 逐字一致 |
| 第二章 海水中的重要元素——钠和氯 | 第二章 海水中的重要元素——钠和氯 | ✅ 逐字一致 |
| 第三章 铁 金属材料 | 第三章 铁 金属材料 | ✅ 逐字一致 |
| 第四章 物质结构 元素周期律 | 第四章 物质结构 元素周期律 | ✅ 逐字一致 |

**章级 4/4 一致**——说明章表确实是 2019 人教版 A 版口径。但**节级没对齐**，抽查就看到三类偏差：

1. **合并**：我们的主题把官方两个节并成一个（`第一章·离子反应与氧化还原` = 官方「第二节 离子反应」
   + 「第三节 氧化还原反应」）；
2. **错位**：`第一章·物质分类与转化·电离平衡` —— 「电离平衡」是**选择性必修1 第三章**的内容，
   挂在必修第一册第一章下，属归位偏差（这类会被用户看到目录时一眼发现）；
3. **占位名**：出现 `第二章第三节` 这种只有节号没有名字的主题。

（这三类是否要改，取决于一个产品口径：**章节树按教材 1:1 对齐，还是允许按知识组织重组**——
见第 7 节。）
