# 「覆盖」的可复核口径设计 · 2026-09-15

> **回答的问题（用户决定 D-5）**：既然外部不存在可核验的权威"高考考点总数"，"全覆盖"这个验收标准应该改成什么、怎么建立、能不能被第三方复核？
> **性质**：研究 + 设计，**不含施工**。所有事实标证据等级；`[本轮实测]` 为我亲自运行得到。
> **配套**：问题登记册 B 类条目（`docs/kb-problem-register-2026-09-15.md`）。

---

## 1. 结论先行

**"全覆盖高考考点"这个说法必须废弃，替换为"覆盖《普通高中课程标准（2017 年版 2025 年修订）》内容要求的 X / Y 条，其中 Z 条待定"。**

三条理由，各有官方依据：

1. **考试大纲已废止**。国办发〔2019〕29 号《国务院办公厅关于新时代推进普通高中育人方式改革的指导意见》原文：**"实施普通高中新课程的省份不再制定考试大纲。"** 教育部教育考试院高考栏目的"考试大纲"分类页**最新条目停在 2019-01-31**。〔官方〕
2. **《中国高考评价体系》明确不界定范围**。教育部发布的考试中心负责人答记者问原文：**"中国高考评价体系不是考试大纲，也不是界定考试范围的规范性文件。"**〔官方〕
3. **官方指定的命题依据就是课程标准**。同一份国办发〔2019〕29 号："学业水平选择性考试与高等学校招生全国统一考试命题要**以普通高中课程标准和高校人才选拔要求为依据**……**命题要符合相应学业质量标准**。"〔官方〕

所以**课标内容要求是这个国家里唯一可引用的"范围"权威**。而它的可复核性，我本轮已经验证到位：

> **`[本轮实测]`** 教育部 2020 年修订版课标官方 ZIP 今天仍可下载：`http://www.moe.gov.cn/srcsite/A26/s8001/202006/W020200603315372317586.zip` → **HTTP 200，`Content-Length: 38598043`**，与项目 `source-register-2025-v1.json` 里登记的 `contentLengthBytes: 38598043` **逐字节吻合**。四科（数学/物理/化学/生物）PDF 与 pdftotext 文本已在本地落盘可用。

## 3. 设计：三层对照表

### 3.1 数据模型（照抄 1EdTech CASE 的最小内核）

外部有成熟先例：**1EdTech CASE**（Competencies and Academic Standards Exchange）把标准对齐抽象成三类实体——**框架文档（CFDocument）/ 条目（CFItem）/ 关联（CFAssociation）**，其官方定位是"to ensure alignment of digital content"〔外部研究，1edtech.org 官方页〕。国内**没有**等价物（国家中小学智慧教育平台的公开通道只到"教材资源"粒度，无条目级模型）〔外部研究〕。

本项目照抄最小内核即可，不做完整 CASE API：

```
A 层（基准·权威）  curriculum_statement   —— 课标内容要求条目
B 层（参照·可选）  textbook_section       —— 人教版 册/章/节
C 层（目标）       knowledge_node         —— KB 原子节点（已有）
关联              alignment              —— A↔B、B↔C、A↔C 的映射，每条带证据
```

**每条 alignment 必须携带的证据字段**（这是"可复核"的全部含义）：

| 字段 | 内容 |
|---|---|
| `sourceLocator` | 课标 PDF 页码 + 原始编号（如"第 18 页，必修：预备知识，原始编号 ①"） |
| `targetRef` | 目标侧标识（章节 slug 或 `kb:…:atomic:<slug>`） |
| `evidencePhrase` | 支撑该映射的**原文片段**（提案校验器已强制要求它逐字出现在捕获的源文本里——这套机制已在 `tools/curriculum_coverage/proposals.py` 实现） |
| `reviewState` | `DRAFT` / `AI_REVIEWED` / `HUMAN_REVIEWED` / `UNDECIDED` |
| `reviewer` + `reviewedAt` | 谁、何时（**AI 复核必须显式标为 AI，不得冒充人工**） |

外部范本：`haojing8312/cn-k12-math-knowledge-graph` 的每条边带 stable edge ID + trace ID + source type + release hash，且**把 596 个待定主题中的 438 个显式保留为"未定"，拒绝写成"确认无前置"**〔一手项目文档〕。这个形态直接适用于本项目的 A-15（1489 条前置边）。

### 3.2 计数单位与核算规则（**必须随表公布**）

课标各科的编号体系不同〔外部研究，官方 PDF 现场核对〕：

| 科 | 编号形式 | 我重计数的 2020 版条目数 |
|---|---|---|
| 数学 | 圈号 ①②③… | 132 |
| 物理 | `x.y.z` 三级 | 137 |
| 化学 | `x.y` 二级 | 63 |
| 生物 | `x.y.z` 三级 | 120 |

> **注意**：这组数字是我按各科原生编号规则**现场重计数**得到的，**不是官方数字**——教育部从未公布过"内容要求条目数"〔未找到〕。而且它与项目的 2025 版候选数（305 / 138 / 73 / 142）**无法用同一规则对齐**（版本差异 + 计数口径差异叠加）。

**所以核算规则本身就是产物的一部分**：必须同时公布 ① 基准 PDF（含 SHA-256）② 计数脚本 ③ 计数口径（哪一层、哪些块、编号规则）④ 重算命令。**没有这四样的覆盖率数字不可复核，等于没写。**

### 3.3 覆盖状态的取值与分母

对每条课标内容要求条目，判定四态之一：

| 状态 | 含义 |
|---|---|
| `COVERED` | 至少一个 KB 原子节点以 `HUMAN_REVIEWED` 的 alignment 对应它 |
| `PARTIAL` | 有对应节点，但节点的材料/边界未完成（对应登记册 A-01/A-10） |
| `NOT_COVERED` | 确认为空 |
| `UNDECIDED` | 未裁定（**不允许默认落进 `NOT_COVERED`**） |

**覆盖率 = COVERED / (总数 − UNDECIDED)**，且**任何时候都必须同时公布分子、分母、以及 UNDECIDED 的绝对条数**。只报一个百分比是不合格的。

这条纪律的来源是外部的直接教训：`cn-k12-math` 明确"AI 审核不会被描述为人工审核"、并把 438 条未定显式留存〔一手项目文档〕；IR 侧 Vorhees 2009 也证明"显著差异也可能是错的"，因此**分母口径与未定项必须暴露**〔A 级〕。

### 3.4 分层措辞（**按科目分别声明**）

课标自己写明了学业质量水平与考试的对应关系，四科**不一致**〔外部研究，各科官方 PDF 原文〕：

| 科 | 2020 版对应关系（逐字） |
|---|---|
| 数学 | **"数学学业质量水平二是高考的要求，也是数学高考的命题依据"** |
| 物理 | "**学业质量水平4** 是用于高等院校招生录取的**学业水平等级性考试的命题依据**" |
| 化学 | "**学业质量水平4** 则是化学学业水平等级性考试的命题依据" |
| 生物 | "**学业质量水平四** 是学业水平等级性考试的命题依据" |

⚠️ **2025 修订版把级数改了**：据修订组署名解读，**物理与数学的学业质量已重构为三级水平**〔外部研究，**单一来源待验证**——课程教材研究所官网 412 反爬，官方发布文本未取得〕。因此**基线若选 2025 版，这张对应表必须以 2025 版 PDF 的"学业质量水平与考试评价的关系"原文重新定位**，不能照搬 2020 版。

对外话术的可辩护上限：
- ✅ 可以说："覆盖 2025 课标内容要求 X/Y 条"
- ✅ 可以说："对齐至[该科]课标学业质量水平[对应层级]"
- ❌ 不能说："覆盖全部高考考点"——官方已明确命题还叠加"高校人才选拔要求"，且高考评价体系不界定范围

## 4. 建议的落地路径（三步，前两步不需要新品）

### 第 1 步：恢复四科基线（**可立即做，全部要素已在手**）
1. 从镜像重新下载四科 2025 版 PDF（`documentUri` 已登记；**本轮已验证镜像存活且字节数吻合**）。
2. 逐份对照 `source-register` 的 `contentFingerprint` 做 SHA-256 核验 —— 三份在盘 PDF 已证明这条路走得通。
3. 重跑 `tools/curriculum_coverage/extractor.py` 的四科子集 → 产出**四科专属**的 candidates + ledger（当前是九科混装且数学缺失）。
4. 把 `mappingState` 从 `DRAFT_UNREVIEWED` 推进到 `REVIEWED` 需要人工逐条裁定；**在裁定完成前，覆盖表的分子一律为零**——这是诚实的，也是这套设计的意义。

### 第 2 步：建 A↔C 两层对照（**建议先只做两层**）
**不要把教材章节层（B）作为第一版的前置条件。** 理由：结构化 TOC 数据不存在，课标官方渠道不提供，平台页图带使用限制且非结构化〔外部研究〕。B 层作为**可选增强列**，后续用 OCR 录入并标注来源与使用限制。

第一版对照表只需：`课标条目 ↔ KB 原子节点`，每条带证据定位与审校状态。这就足以支撑"覆盖 X/Y 条"的断言，且**完全可复算**。

### 第 3 步：处理 182 条待裁提案
它们集中在 25 个模块（数学 3 + 生物 22）——正是机械提取失败、需要人工原子化的那些。**不处理它们，这 25 个模块在覆盖表里就是永久 `UNDECIDED`**，分母永远不完整。
