## 1. 目标与范围

### 1.1 目标

把产品从"四个功能栏目 + 一个讲题聊天"重构为：**错题本（学习）垂直领域的智能体应用**——
智能体是内核，五个栏是它的工作现场；会话按栏隔离、不绑题（题只是本轮附件）；掌握度数值永远由
本地投影算出，智能体的"不断改写"发生在知识层；复习只是智能体的一种交互（全屏卡片流 + 判题限定）。

### 1.2 范围与非目标

**范围**：五栏结构、会话事实模型收敛、工具面泛化、候选与提案生命周期。

**非目标（明确不动）**：
- 学习科学内核：`LearningProjector` / FSRS / 投影 / 排程算法（D1 保留其数值权威）。
- 知识库生产线（`tools/kb_build` 及其门）。
- 排版与编排（底栏格数、每屏视觉）——推迟，单独立项。
- 学习档案视觉（插眼 4）——必须先问用户。

## 2. 产品结构（表）

### 2.1 五栏 + 全局成分

```text
栏（按功能分区；栏数 ≠ 底栏格数）
└── 入口（同一栏可有多个入口）
    └── 成分（会话区 / 任务进度 / 静态视图可共存，不互斥）
```

| 栏 | 入口 | 会话？ |
|---|---|---|
| **智能体** | 会话（每次进入默认新开） | 有（本栏自己的会话区，不出栏） |
| **复习** | ① 错题复习 ② 知识点复习（两个入口、同栏） | 有（**按入口分会话区**：错题复习、知识点复习各一个区，互不相串；随轮次结束；历史归学习档案） |
| **错题本** | ① 错题本（静态查看）② 录入（拍照 / 批量导入） | 无 |
| **学习档案** | 只读可视化 | 无（修改经智能体栏提出） |
| **设置** | 配置 | 无 |

**全局成分**：
- **悬浮球 = "它的动静"总闸**（S3）：可移动、可展开；点开一层 = **在跑的大任务**（目前只有
  "错题本录入"这一类）+ **各栏待确认**（未读小红点并入悬浮球）。按需出现，不是常驻装饰；
  **不含"最近动作清单"**。

### 2.2 每栏成分（已裁定）

**智能体栏**
- 默认主成分：会话流；进入即新开；会话不出栏。
- 覆盖层 1：会话历史（列表；点一条回去继续；返回键回当前会话）。
- 覆盖层 2："它最近做了什么"（可问条目；被问时用检索卡/附件卡回答）。
- 空态能力目录：新会话空白时展示"它能干什么"；有内容后让位。
  **每条能力带一句可点的示例**（"试一句"：点即作为首条消息发出，S5），文案设计必须贴切。
- 两个能力：检索错题卡（"打开"跳错题本详情）；智能体驱动的选择导出（检索 → 用户勾选 → 本地排版 → 导出可打印文件）。

**复习栏**（铁律：**卡片流负责任务，会话层负责说话，它只在会话层开口**；两个入口、同栏、各一个会话区）
- **入口 ① 错题复习**：进入即"今天的复习"，无单独首页；空态 = "今天没有到期题" + 一句解释。
- **入口 ② 知识点复习（保留，卡片流形式）**：与错题复习同形态——一卡一个知识点测验项：
  作答 → 判定 → 下一张。基于既有 `KNOWLEDGE_QUIZ` / 知识点复习队列，**形态从聊天式改为卡片流**；
  判题与写掌握度走既有 `knowledgeQuizMasteryVerdict` + `KnowledgeQuizFeedbackWriter`（D1 不破）。
- 两入口共同规则：默认主成分 = **全屏卡片流**（错题卡：题面→作答→判定结果投影；知识点卡：
  测验项→作答→判定结果投影）。顶部轻量进度（"今日 3/12 · 约 8 分钟"）。
  **不显示任何入选原因**——`ReviewReason` 整体删除（不计算、不显示、不预生成；
  `review_log.planned_reason` 与校准特征一并清理）。
- 会话层：卡片旁一个小按钮，全屏覆盖、可退回；退回时卡片状态完整保持（计时、已用提示、已填答案）。
  **判题限定（接内核）**：未作答前只能提示（`solutionRevealed` 强制 false，pretest 路径；
  看答案后答对仍按内核规则 EXCLUDED）；**作答且判定后（无论对错）回复不限制**。
- 判题是卡片流专属组件，不需要开会话：作答 → 提交 → 判定直接投影在卡上。
  **判定卡内容（D-Q6-6）**：判定 + 学生答案 + 一行"评价" + 灰色小字可展开的判定依据（默认收起）。
- **备注回响（S1）**：判定后卡上显示该题的**备注披露**——默认收起，点击后展现全文（不默认铺开）。
- 覆盖层：今日队列预览；完成结果（仅数据）。
- 复习历史不在本栏（归学习档案）。

**错题本栏**（无智能体、无会话）
- 入口 ① 错题本（静态）：主成分=列表。
  - **标题单源** = 当前 `revision.title`（列表/关系卡/详情同源）。
  - **筛选**：一层=科目→板块；**删"知识点"筛选层、新增"录入时间段"**。
  - **排序**：仅"最近更新 / 最近录入"两值，**默认时间先后**（删 NEXT_REVIEW / LEAST_MASTERED）。
  - **无删除/回收站**：归档即"移出"；`TRASHED` 死枚举值删除、"可能已删除"文案修正。
  - 覆盖层 = 详情页（**备注保留**、卡标题去掉"错因"二字）、批量选择、导出打印（整页覆盖可退回）。
  - **归类修订**：**删离线自由文本编辑器**；保留在线模型建议 + **从知识树选择**
    （接线 `observeOrganizationOptions`）。
  - 后台产出角标层（机制壳保留：小红点→建议清单→采纳/改/忽略；第一版内容为空）。
- 入口 ② 录入（任务区，**单题与批量统一为"录入"**）：拍照/批量导入同一入口与流程；可视化进度；
  **跨导航不暂停**；进度在悬浮球；**"没存入的题"（待处理草稿）在录入界面内可见，不放错题本栏**
  （顺带关 KD-17）。
- **导出不随页面丢 → 改后台任务**（优先级低于"录入统一/待处理"，实施时专门设计）。
- "问这道题"出口：详情页入口 → 跳智能体栏、以该题为本轮附件开新会话。

**学习档案栏**（只读、无智能体、无会话）
- 主成分：概览（本周完成 / 掌握带分布 / 薄弱点 / 连续学习）。
- 覆盖层：掌握度全览（含"**最近答错的知识点**"分区——系统自动投影、只读、不可手动添加；
  每行=知识点+最近答错时间+相关题+掌握带，可带它去智能体栏，D-Q6-7）→ **无证据链下钻**
  （用户裁定：内容太多不简洁；"看证据"入口若保留必须刻意弱化）；
  **复习历史**（自复习栏移入）。
- 交界规则（与错题本）：**数据单源、视图分栏、动作定界**——学习档案里的题只做两件事
  （被看见、点开跳错题本详情），无任何管理动作。

**设置栏**：配置 = 智能能力（Provider/模型/Key/能力测试）、提醒、排程与考试日历、数据与存储。
整理现有设置页，不重新发明。

### 2.2b 智能体交互面（点 3 裁定，2026-09-25）

- **C1 一条交互面**：智能体只有一个交互面，差异只在**本轮附件与所在栏**。
  作废一切旧框架词（大厅 / 会话页 / 两条正文）——统一叫**智能体栏、会话区、一条交互面**。
- **致命档 6 条（必须修）**：
  - A1 进入**不接管旧会话**（空态 = 能力目录）；
  - A2 **停止 + 重试 + 复制**动作条（参考主流交互形态）；
  - A3 **流式全阶段统一**（任何地方都有流，**不分 plan**）；
  - A4 "确认加入错题本"**真实落库**；
  - A5 **输入框永不消失**（不可用时提示语参考主流报错文案）；
  - A6 Route B 工具轮**不流进正文**。
- **严重档 7 条**：
  - B1 工具结果进 UI = **加粗灰色小字内联**（点开看详情，不是工具卡）；
  - B2 真实按钮（不用怪文案）；
  - B3 待发附图改 `rememberSaveable`；
  - B4 无题轮工具返回空、不报错；
  - B5 **删 UI 派遣预算，只留内核账本**；
  - B6 多轮追加不重置；
  - B7 会话标题 = 首条消息截取。
- **结构档 3 条**：
  - C2 对话状态收进**一个 `TutorConversationViewModel`**（消灭两个 ViewModel + 散落 `remember`）；
  - C3 **采集链复用**（`CaptureAcquisitionLaunchers` / `CaptureCache`）。

### 2.3 会话规则

- 会话**按会话区（入口）隔离**（D-Q1F + D-Q1M10）：智能体、错题复习、知识点复习各一个会话区，
  只能在本区查看。
- **不绑题、不绑知识点**（D-Q1H）：题/图/知识点只是**本轮附件**。
- 每次进入默认**新会话**；**空会话不落库**（发出第一条消息才建会话行）；历史只列有内容的会话。
- 会话标题 = 首条消息自动截取 + 时间（不调模型生成）。

## 3. 智能体行为契约

### 3.1 工具面

- **单一声明、全局同型**（ADR 0001 内核部分继续有效）：5 个工具
  （`KNOWLEDGE_READ` / `NOTEBOOK_READ` / `MASTERY_READ` / `NOTEBOOK_WRITE` / `MASTERY_UPDATE`）。
  差异只能来自三个来源：**栏上下文**、**本轮绑定**、**本地门**。禁止按栏分工具面。
- **无题轮**：读工具返回"本轮无可读范围"，写工具返回"无可写目标"——**不报错、不消耗预算**。
- 协议广告两套并存（Route A 严格 schema / Route B prompt 文本）在实施中收敛。

### 3.1b 智能体的统一底层（D-K4）

智能体所有"动到外面、动到事实"的行为，都经过**同一个底层**（一层，一个语义）——
**"能不能发、发什么、能不能写、写多少"**，由这一个底层统一回答：

- **发送**：已配置模型 + 支持所需输入（含图片）才发；图片只从规范资产库按字节核对后流出。
- **写入**：掌握证据过 `MasteryWriteGate`；绑定改动过重拆 hook。
- **预算**：逻辑操作派遣上限（`MAX_DISPATCHES`）。
- **曝光**：答案曝光键（精确表面底部进视口才记）。

就这些。原来的分层机制（manifest 自校验、8 分支核对、契约注册表、TTL、`prohibitedData`）
**删除并并入这一个底层**——它们要么只活在测试里、要么运行时到不了；契约测试保留为测试锁，
文档照实写清。

### 3.2 本地动作白名单（第一版已裁定）

| ID | 动作 | 权限 |
|---|---|---|
| `OPEN_PROBLEM` | 打开某题（跳错题本详情） | 确认卡 |
| `SAVE_TO_NOTEBOOK` | 当前题加入错题本 | 确认卡（`NOTEBOOK_WRITE` 的 ask 档） |
| `START_EXPORT` | 发起选择导出（生成可打印文件） | 确认卡（插眼 5 见 §6） |
| `ADD_TO_REVIEW_PLAN` | 提出复习计划调整 | 模型提出行为 → 请求用户同意 |
| 重拆 | 自动执行 + 本地 hook 拦；不确定/错误/被拦才问用户 | 自动 + hook 门 |

- 本地动作 ≈ 工具的一种：**执行需学生确认**；**执行结果回喂模型上下文**。
- 模型只能"选"不能"造"：固定 ID + 固定参数形状，本地定义。

### 3.3 权限档

| 档 | 对象 | 行为 |
|---|---|---|
| allow | 三个读工具 | 自动执行 + 工具卡可见 |
| ask | `NOTEBOOK_WRITE` / `SAVE_TO_NOTEBOOK` / `OPEN_PROBLEM` / `START_EXPORT` / `ADD_TO_REVIEW_PLAN` | 确认卡 |
| auto+visible | `MASTERY_UPDATE`（掌握库写入） | **全自动、不需批准**；行为全程可见；被拒给理由 |

**`MasteryWriteGate` 升档为唯一信任边界，三条工程要求**：
1. 门常数（0.7 置信 / 锚底线 1 与 2 / 12h 冷却 / 50 会话 / 100 learner / 非确认锚半权）必须有
   **实测校准依据**（挂研究任务，遵守"算法参数须科学落实"纪律）。
2. 每次写入（含被拒）在工具卡可见，被拒给理由。
3. 掌握变化可追溯到证据（学习档案的证据入口已弱化，追溯以工具卡与绑定事实为主）。

### 3.4 呈现（Codex 形式，工具结果 = 加粗灰色小字内联）

- 流式期间：探索类调用聚合为一个**活单元**（"正在查阅：错题本、知识库…"），随流更新；
  轮次结束时收进会话流，折叠为"已查阅 · N 项"。
- 工具调用结果：**照常进上下文**，并在交互流里以**加粗灰色小字内联呈现**（点开可看详情，
  含被拒理由）——不是独立卡片组件。
- 思考块：生成中保持展开，答案到达后折叠成一组（与既有讲题思考链 UX 一致）。

### 3.5 附件规则

- **内联卡四类**（allowlist，未知类型降级纯文本）：讲解结构卡（步骤流/对照表/公式推导）、
  选择卡、结果/提案卡、依据卡（"看证据"按钮为弱化入口）。
- **引用类别已删除**：正文对象名一律文字；能点的只有本轮附件本身与卡内按钮。
- **无附件场景**：纯文本讲解、数据摘要、寒暄 → 纯文字。
- **来源标签（S2）**：它引用课本材料时，在相应位置标一句来源（"来自：必修一·函数单调性"），
  **不可点开原文**，只标签。
- **禁止**：整页/整列表塞进会话（只准 ≤N 条摘要卡）；未被打扰时插播卡片（走角标）。

## 4. 内核设计

### 4.1 会话事实模型（K1）

- **唯一对话文本权威 = `tutor_message`**；`model_task` 只留账本（状态/预算/原始输出 JSON），
  **不再存第二份渲染文本**。
- 会话行新增**会话区判别列**（`AGENT` / `REVIEW_MISTAKE` / `REVIEW_KNOWLEDGE`，集合开放）。
- 本轮附件（题引用 / 图引用 / 绑定）挂在消息行上。
- 表去留：保留 `tutor_conversation`（+column）、`tutor_message`、`tutor_message_source_asset`、
  `tutor_answer_exposure(_outcome)`、`learner_chat_evidence`；并入/退役 `tutor_session`、
  `tutor_turn_response`、`tutor_session_problem_anchor`。
- 实施铁律：新字段 strip 空载体 + bump 指纹（`bf8be888` 教训）；迁移非破坏、旧行全部可读；
  唯一槽（`conversation_id, ordinal`）与逻辑操作唯一性不破。

### 4.2 候选与提案生命周期（K3）

**自动重拆**（发现拆错自己改 + 本地 hook 拦）：
- hook 判据四条：①新节点真实存在且同科（或 `pseudo`）；②该题历史证据可按新绑定重放；
  ③冷却内不重复；④**学生已确认的绑定（`USER_CONFIRMED`）一律不自动碰，只能问**。
- 通过 → 改绑定 → `LearningProjector.replay` 重放 → 落绑定变更事实 → 工具卡可见。

**被拦下的 → 问人**：确认卡，采纳则同自动路径，忽略留痕且冷却内不再自动提。

**学生纠正请求**：在会话里提出 → 智能体按规则判断（不一定接纳）→ **拒绝留痕并给理由**。

**冷却占位值（待校准，实施时做细致规划）**：同一题 12h 内不重复重拆；每会话自动重拆 ≤3 次；
被拒后 30 天不再自动提。**口子留好**：常数集中、可配置、带实测校准流程。

**留痕**：绑定变更事实（旧→新、发起者 auto/hook/人、重放影响 N 条证据）。具体给用户看什么、
规则细节，**实施时再细致决策**（用户裁定）。

### 4.3 拆分与绑定（D-Q1G 修订版）

- 入库步骤内**自动**完成归类与原子知识点拆分，随保存成立权威绑定，进入掌握库加权视野
  （加权 = 绑定参与投影与排程，**不是写数值**；D1 不破）。
- 拆分失败挂 `pseudo:<SUBJECT>` 占位，不阻塞入库。
- 重拆/换版按 §4.2 生命周期；换版重放历史，语义 = "绑定改事实、投影重算、数值自然变"。

## 7. 验收标准草案

1. 五栏结构落地；会话按**会话区（入口）**隔离、跨区不可见；进入即新会话、空会话不落库。
2. 复习栏：两个入口（错题复习 / 知识点复习）均为全屏卡片流；判题限定（未作答只提示、判定后放开）在真机上走通。
3. 错题本：静态查看与录入分离；录入跨导航不暂停、进度在悬浮球。
4. 学习档案：只读；复习历史在位；无证据链下钻。
5. 会话事实模型收敛：`tutor_message` 是唯一文本权威；旧行全部可读。
6. 工具面：单一声明；无题轮不报错；权限三档生效；`MASTERY_UPDATE` 全自动且行为可见、被拒给理由。
7. 本地动作白名单五动作生效；确认卡挂起有恢复路径（插眼 5）。
8. 自动重拆 hook 四判据生效；被拦问人；冷却占位值生效且留有校准口子。
9. 掌握度数值仍然只由投影写出（D1 回归测试）。
10. 文档作废清单（§5）逐条执行。
11. 无模型 / 进程死亡 / 切栏中断的核心路径不丢状态（既有恢复纪律延续）。

## 8. 实施约束

- 指纹纪律：任何新增模型输入字段必须 strip 空载体 + bump schema 指纹（4 条必测用例）。
- Room 纪律：新表/新列 → bump `STUDY_DATABASE_VERSION` + 非破坏迁移 + 导出 schema；schemas 目录只增新版本文件。
- 唯一槽与幂等：`(conversation_id, ordinal)` 唯一；命令幂等收据延续。
- 共享工作树：提交用显式文件列表；本规格及其后续文件未经要求不提交。
- 规模门：新文件遵守 600/1000 行门（`DEVELOPMENT.md`）。
- SQL 纪律：所有数据库查询对外部输入一律**参数绑定**，禁止拼接/format/f-string 组装 SQL（生成期安全约束）。
- 清理项（随重构一并执行）：`LEARNING_SUMMARIZE` 任务及其链路（学习周报已砍，2026-09-25）。
- 学生语言：界面不出现内部机制词（工具名、门、hook、投影一律翻译成人话或收进工具卡二级详情）。
