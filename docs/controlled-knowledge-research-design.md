# 受控知识资料补充方案

## 裁决

联网检索只作为本地知识目录缺少细分内容或依据不足时的补充通道，不进入学生的正常讲题主路径。检索结果只是待核验资料，不能直接成为知识分类、学习顺序或学生掌握情况。

生产闭环必须保持：

`本地汇总待完善分类 → 检索候选资料 → 安全下载与指纹核验 → 独立人工审校 → 版本化内容包 → 数据库事务导入 → 关闭对应待完善项`

禁止：

- 把题目原文、题图、答案、对话或学生学习记录发送给搜索服务。
- 让模型生成的知识名称或关系直接写入正式知识目录。
- 把搜索摘要当作原资料依据。
- 未经许可复制教材、教辅正文或平台资源。
- 由学生承担资料核验、分类修正或数据库录入。

## 研究依据

教育部普通高中课程方案和课程标准是本项目确定学科范围、内容边界与术语的首要依据，而不是直接照搬某个第三方题库。课程教材研究所已说明 2025 日常修订版正式颁布实施，因此新内容包以《普通高中课程标准日常修订版（2017 年版 2025 年修订）》为当前基线，2020 修订版只保留为历史差异来源：

- [课程教材研究所：普通高中课程标准 2025 日常修订版专题解读](https://www.ictr.edu.cn/policy/cheng/p/11.html)
- [教育部：普通高中课程方案和课程标准（2017 年版）](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/201801/t20180116_324668.html)
- [国家智慧教育平台资源入库与管理相关规范](https://www.moe.gov.cn/srcsite/A16/s3342/202211/t20221108_979699.html)
- [教育部教育数字化标准规范](https://hudong.moe.gov.cn/srcsite/A16/s3342/202407/t20240703_1139249.html)

资料治理上，官方公开材料可作为范围和术语依据，但“官方”不自动等于“允许复制”；教材与教培材料必须取得明确授权。只能参考的资料仅保存题名、发布者、地址、定位、指纹和经审校后的独立归纳，不保存复制正文。具体来源的权威性与内容使用权分开登记，见 [高中知识资料来源与使用边界](knowledge-source-governance.md)。

研究表明，概念之间的先修关系可以从课程资源中辅助推断，但仍需明确的课程语境和验证，不能把自动推断视作事实：

- Liang 等，[Measuring Prerequisite Relations Among Concepts](https://doi.org/10.18653/v1/D15-1193)
- Roy 等，[Inferring Concept Prerequisite Relations from Online Educational Resources](https://doi.org/10.1609/aaai.v33i01.33019589)
- Desmarais 与 Baker，[A review of recent advances in learner and skill modeling](https://doi.org/10.1007/s11257-011-9106-8)

GitHub 上可找到课程标准结构化项目，例如 [Common Standards Project](https://github.com/commonstandardsproject/api)，可借鉴版本化标识和 API 组织方式；其内容不是中国高中课程依据，也不能直接导入本项目。

## 本地与联网的职责

### 本地负责

- 按科目聚合待完善分类，只形成短查询、期望板块和涉及题数。
- 从正式知识目录召回候选、读取学习顺序和学生单科学习情况。
- 校验资料地址、响应状态、类型、大小和 SHA-256 指纹。
- 保存资料元数据、审校结论、版本和来源定位。
- 在一个数据库事务中导入通过审校的知识点、关系和对应来源，并关闭待完善项。
- 计算学生掌握情况；联网资料不能改写学习记录。

### 搜索服务负责

- 只接收不含学生数据的短查询。
- 返回候选资料的标题、发布者、地址、类别、许可状态和排序。
- 不接收题图、题面、学生答案、对话或学习画像。

### 大模型负责

- 在完整知识目录召回不足时提出更细的候选名称和检索方向。
- 在审校工作台中辅助比较资料、发现同义项和可能的直接学习顺序。
- 所有结果均保持候选状态；没有独立审校不得进入正式目录。

## 来源优先级与许可

1. 教育部、教育考试机构及课程标准发布机构的公开材料。
2. 已取得本项目使用许可的教材。
3. 已取得本项目使用许可的教培资料。
4. 第三方教培、教材出版机构和公开教学平台的参考资料；未取得复制许可时，只保留元数据、定位和经审校后重新撰写的知识点、方法模型、例题结构与边界，不复制题库或正文。
5. 仅供参考的公开研究或机构资料，只保留元数据、定位和经审校结论。

搜索结果先按以上优先级排序，再按服务返回顺序稳定排序并去重。一次最多保留 12 个候选，最多下载核验 4 份资料；个别资料失败不阻断其他资料，但全部失败时不建立审校任务。

搜索服务声明的“官方”或“已授权”不能直接信任。本地只把中国政府域名上的课程标准声明视为官方公开来源；教材或教培资料只有在本地许可主机清单中明确登记后才能保留“已授权”状态。其他声明全部降为普通参考资料，再交由独立审校。

## 安全与资源上限

- 只允许不含账号信息、片段标识和非标准端口的 HTTPS 命名主机地址。
- DNS 解析结果必须全部是公网地址，并在请求期固定解析结果。
- 禁用系统代理、重定向、失败重试和跨主机跳转。
- 只接受完整的 HTTP 200 响应；206、3xx 和错误响应全部拒绝。
- 只接受 PDF、HTML、XHTML 和纯文本。
- 解压后的单份响应不超过 16 MiB，连接、读取和总调用均有超时。
- 下载内容使用按需增长的有界内存缓冲区计算指纹，完成或失败后清零临时字节，不预分配整份 16 MiB，也不把原文写入学生数据库。
- 审校包只保存查询、资料元数据、类型、长度、指纹和核验时间。

## 数据库与检索性能

当前正式知识检索和学习情况读取已经有独立的 Room 索引和规模测试：

- 12000 个知识点、11999 条直接学习顺序关系，完整召回十次 p95 为 23 ms，门槛为 150 ms。
- 单个学生 12000 条学习情况读取十次 p95 为 95 ms，门槛为 250 ms。
- 待审校队列按最大单页 256 个资料包、每包 4 份资料读取，使用一个资料包查询和一个批量资料查询；最新十次 p95 为 18 ms，门槛为 250 ms。
- 候选上限、分科隔离、直接关系定向读取和批量参数分片均在数据库边界执行。

这些结果证明当前本地数据结构在 API 36 x86_64 模拟器上通过性能门槛；不等于真实 ARM 设备已经验收，也不证明召回质量已经过关。质量门槛还需要完整九科目录和人工标注题集，以 Recall@K、Precision@K、跨科误召回率和细分层级正确率评测。

联网补充链路本身采用固定上限，数据库数据量不会决定单次网络请求数量。网络时延不应阻塞讲题或错题保存；资料补充在后台独立进行。

## 学生端语言边界

学生端只使用“知识点”“板块”“学习顺序”“找到相关知识点”“学习情况”“分类正在整理”等日常说法。数据库表名、工程类型名、图结构名、检索术语、协议字段和审校状态不得出现在页面、通知、无障碍朗读或模型回复中。

该限制也适用于错误提示：学生最多看到“这部分分类还在整理，不影响保存和讲解”，不承担内部处理动作。

## 当前实现状态

已实现：

- 不含题目和学生数据的受控检索查询合同。
- 候选资料优先级、去重、数量上限和部分失败隔离。
- HTTPS、公网 DNS 固定、无代理、无重定向、超时、响应类型/大小与 SHA-256 核验。
- 核验资料只进入独立审校队列的领域边界，不能自动导入。
- 待审校资料包使用 Room 持久化；相同内容可安全重放，相同标识的不同内容会被拒绝。
- Room v26 已将讲解资料和题库实体分开：允许概念讲解、方法模型、易错说明和含完整解答的例题，但这些资料没有作答、评分、学习证据或复习排程权限。
- Room v28 将来源权威性与内容使用权拆开：历史来源默认只能独立归纳；节选或改编必须同时具备明确许可标识、许可地址和署名，参考资料不能直接复用正文。
- 批准或拒绝决定记录审校者、说明和时间；决定使用事务与状态条件写入，可精确重放但不能被另一决定覆盖。
- 正式知识目录的来源、关系、版本、无环校验和事务导入。
- 本地知识召回和单科学习情况的规模性能测试。

尚未完成：

- 生产搜索服务适配器。
- 内部审校工作台，以及“已批准资料包 → 正式知识内容包”的受控组装入口。
- 九科讲解资料的完整覆盖和多来源逐条审校；当前两份数学样例只证明结构可用。
- 全九科细粒度知识目录及足量直接学习顺序。
- 人工标注检索质量评测集。
- 真实服务商网络组合与 ARM 真机性能验收。

因此当前裁决是：数据结构和本地性能已通过当前模拟器门槛；受控资料核验、持久待审校和不可改写审校决定已落地；生产搜索、内部审校界面、正式内容包组装、知识覆盖和真实召回质量仍未完成。
