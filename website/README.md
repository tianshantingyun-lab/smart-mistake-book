# 智能错题本官网

独立的 React + Vite + TypeScript 官网与演示管理后台。它不会修改 Android 业务模块，也不会在演示模式中保存 APK 二进制、伪造下载地址或加载第三方分析脚本。

## 本地运行

```bash
npm install
npm run dev
```

公开官网位于 `/`，未公开的演示后台位于 `/admin`。后台内容保存在浏览器版本化 `localStorage` 中，上传图片保存在 IndexedDB 中；“恢复初始数据”会恢复内置文案与 App 媒体，并清空演示文档、版本和上传图片。媒体库支持名称/替代文本搜索、显隐筛选和上传资源删除；内置资源以及仍被产品页引用的图片不会被误删。

产品讲解页固定使用 `/product`，初始为空白未发布草稿。管理员可在 `/admin/product` 通过受控区块增删、复制、隐藏和排序内容；整页发布前，公开导航不会出现产品入口。内置 App 截图保留在媒体库，但默认不公开。

持续维护与自我挑战记录在 `continuous-review.md`；只把经过源码修复与新鲜验证的问题标记为已关闭。

## 验证

```bash
npm run typecheck
npm test
npm run build
npm run test:sites
```

## 接入真实后端

未配置 `VITE_CONTENT_API_BASE_URL` 时使用配套的本地内容网关与演示认证网关。配置后，两者会一起切换到远程模式：公开页面只读取不含草稿的 `PublicWebsiteState`，登录成功后才读取完整管理状态，退出后立即丢弃管理草稿并重新加载公共快照。所有本地存储和远程响应都会经过完整嵌套运行时校验。类型与网关位于 `src/types.ts` 和 `src/gateways/`，完整接口约定见 `api-contract.md`。

分析配置默认为空。即使管理员填写统计平台与站点 ID，也只有在隐私页已发布且访问者明确同意后，稳定事件才会进入分析适配器；当前适配器不加载任何第三方脚本。
